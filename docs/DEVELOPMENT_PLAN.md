- P0：空目录初始化，锁定 Godot，配置 SDK/JDK，完成 APK 构建与真机安装启动。
- P1：固定物理步长移动、单段跳、跳跃缓冲、离台宽限、上方向瞄准、触屏/键盘/手柄输入。
- P2：两种 Resource 配置武器、三类敌人、生命与无敌、拾取、计分和重试。
- P3 初版：工业风单关、Boss 前检查点、两种 Boss 攻击、通关/死亡/暂停闭环。
- P4 初版：代码原创像素画，19 个合成音频，中文界面与 OFL 字体。
- P5 部分：已连接 Android 真机启动、截图、单指操作和后台恢复检查；逻辑自动验证。

## 后续按顺序执行

1. **玩法与关卡打磨**：组织三段遭遇战和跳跃挑战；完善瞄准与触屏布局；用实际试玩验证 3～5 分钟通关目标。禁止用强制等待凑时长。
2. **工程深化**：将 main.gd 中角色、敌人、关卡流程拆分为专用场景/脚本；将敌人、Boss 和遭遇配置移入 Resource；保持现有回归测试。
3. **正式视觉制作**：补齐角色受击/死亡等动作、斜向持枪、Boss 入场和死亡表现、不同地形和背景；建立资产规范和逐项清单。当前程序化像素源代码为可编辑初版资产，不能当作已通过美术终验。
4. **音频打磨**：无缝循环实际听检、密集战斗混音、各类音效差异化和音乐切换过渡。
5. **Android 完整验收**：三指同时移动/跳跃/射击、蓝牙手柄、不同分辨率、安全区、返回键、反复切后台、20 分钟真实游玩和性能采样。
6. **P6 交付**：所有阻断问题修复后更新测试报告、打包完整源文件、形成最终版本；发布包需用户提供正式签名条件。
