## 采样实现

- `scripts/debug/telemetry.gd` 默认关闭，通过 `--telemetry` 或调试数据目录中的 `telemetry.flag` 显式启用。
- 每帧记录单调时钟回调间隔 `frame_ms`、Godot `engine_delta_ms`、模式、位置、静态内存、对象/弹丸/粒子/效果/音效占用。
- `frame_ms` 是应用回调间隔，不是独立 GPU 渲染时间或屏幕呈现时刻。静态内存不是 Android 总 PSS，更不是显存。
- 优化前 v1 的 `frame_ms` 采用 Godot 平滑 delta，后续 v2 已单独记录实际单调时钟间隔；不能把两种口径直接计算成帧率提升百分比。
- 从菜单/暂停/死亡/结算过滤出的战斗样本时长与墙钟跨度分开记录。阶段摘要不自动证明真人操作来源、Boss覆盖或20分钟连续通过。
- 原始 CSV 保存在 `work/polish/`；已采样数据来源与所安装 APK 哈希需对应记录。
