# 操作

- 键盘：A/D 或左右方向键移动；W/上方向键瞄准；S/下方向键下蹲；空格跳跃；J 连续射击；ESC 暂停。
- 触屏：左侧虚拟摇杆，中心死区无动作；水平移动，上推瞄准、斜上推同时移动瞄准，下推下蹲。右下大按钮射击、其左上方按钮跳跃；右上角暂停。摇杆由首次按下的手指占用；动作键按下捕获，滑过另一按钮不会串键，滑离原按钮会释放，回到原按钮可恢复。允许不同手指同时操作。
- 手柄：左摇杆移动和上下操作；A 跳跃；X 射击；Start 暂停。菜单用方向键和 A，设置页用左右调整、B 返回。
- 设置：自动射击、按钮大小、按钮透明度、音乐音量、音效音量、减少闪光、减少震动和低特效；设置立即保存。
- 两种武器无限弹药；金色 S 为散弹拾取物。死亡后恢复普通枪。
- 到达核心入口激活检查点，死亡后从这里重新开始，恢复 3 点生命。
- 切后台自动暂停，返回后需主动继续游戏。

## 平台下穿 / 0.3.2

两关普通架空平台：站稳后，明确按住正下方向，再按一次跳跃，即可穿过当前层。下一层仍会接住角色；长按不会连续下穿，需松开跳跃后再按。下落时可左右移动和射击。斜下＋跳为普通跳跃，实体地面、起点与Boss战场底板不可下穿。

触屏摇杆需向正下方明显推动（纵向至少65%行程、横向不超过25%，且没有水平动作），再点跳跃。键盘S/下箭头＋空格；手柄正下推＋A。手柄实际硬件未测试。


## 五武器与R / 0.5.0

普通步枪、M机枪、五发S散弹、L脉冲激光、F螺旋火球都可按住射击；仍沿用原有移动/蹲下/正上/斜上与下穿操作，不新增切枪键。拾取字母胶囊立即换枪，R胶囊只强化、不替换，重复R不叠加。当前装备和R在HUD显示，L装备时R低亮保留但不加速。

受伤不掉枪，死亡/检查点重试/新关恢复普通枪并清R。每次Boss挑战有一个固定位置的可选S补给，可不拿，普通枪仍可通关；补给不加分不回血，重试重新提供。武器不存入设置或跨关保留。现有三关主题与按钮命中范围不变。
