# 第二轮位图美术样板 / 2026-11-03

用户要求按批准的概念图替换方块拼接美术，并安装真机查看效果。本轮使用内置 image_gen 辅助制作本项目原创位图，生成源图、参考图、提示词和图集坐标均保留。没有引入外部商业游戏素材。

## 实现

- 工厂夜景位图缓慢横向滚动；独立世界坐标平台和地面模块。
- 5×2 透明角色图集：主角姿势切换、红甲步兵、炮台、无人机。
- 2×2 透明场景图集：金属走道、栏杆平台、反应炉门、Boss。
- 切角战术 HUD、斜切生命格；缩小方向按钮并下移操作区。
- 现有物理、命中框、武器和关卡保持；图集矩形在绘制时选取，源 PNG 不被裁切覆盖。
- assets/art/regions.json 已显式加入 Android 导出规则。

源文件说明与提示词：source_assets/art/README.md、generation-prompts.json。
程序绘制入口：scripts/game_view.gd。没有把完整概念截图铺在游戏里冒充交互实现。

## 仍未完成

不承诺与概念图逐像素相同。当前背景为单张细节纹理循环，尚未将远中近景各自完整分层；横向重复边界可能可见。
角色目前使用少量姿势帧，尚未完成完整逐帧跑动、独立受击、死亡动作。
上瞄准使用斜上持枪图，垂直射击姿势及枪口精确同步仍待补齐；Boss 枪口与原玩法弹丸发射点还需统一。
HUD 图标、按钮图形、音频和最终打击特效还需继续制作。
仍为 0.1.0 美术原型，不是最终发布成品。
