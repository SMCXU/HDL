- `tools/device_navigation.py`使用Android单点注入、遥测状态和前台窗口联合检查，设置持久化后恢复原文件；不能代表真人多指。
- `tools/device_replay.py --mode retries --retry-count 23`交替全新开局与第二段检查点，每轮3秒后致命伤，等待演出再重试。前三样本预热，余20个采样另行分析。
- 回放加入run_id，避免旧状态文件误判本轮完成；记录本轮构建身份、总PSS、供电/电池温度与热服务输出；临时配置和新增诊断标志按原状态恢复。

初次逐次追加采样字典，会使自动重试诊断器随记录增加约17KB，干扰“非单调上涨”判断。已在预热前分配固定23槽，逐轮只更新原槽；历史受干扰结果保留work/verification/device-retries-final，不冒充最终无泄漏证据。
