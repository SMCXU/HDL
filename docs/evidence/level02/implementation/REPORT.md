# 0.3.0 双关阶段实现 / 2026-11-04

用户确认原创「暴雨水坝」概念图并授权实施。本报告记录实际实现及证据边界；仍为阶段原型，不能称最终完成。

## 实际接入

- 第一关迁移为独立LevelSpec；原27组、三段检查点与炮台Boss保留。第二关Resource由tools/generate_level02.py生成，原始坐标和编排可追溯。
- 第二关河道→泄洪井→坝顶→主闸四段，24级真实固定平台、二维镜头和地形空间桶；缺口无全局隐形地板，失足恢复位置与扣血分别处理。
- 11组可变普通遭遇，三个关键目标与节点开门；两种机关统一预警/有效/冷却状态。节点破坏关闭对应电区，暂停冻结。
- 检查点快照保存关卡/位置/分数/目标/已触发遭遇/消费拾取，死亡回滚后段收益；CP-E不重复刷节点和分数。
- 独立双臂闸机Boss，双武装→核心→超载；扇形弹、固定锁定射线、可跳冲击波与落点打击；只结算一次。
- 两关选择、第一关真实通关解锁、进入第二关确认、独立分数和旧配置迁移。旧最高分不被当作旧通关证据；debug不会改正式解锁/最高分。设置临时写入/替换并保留恢复文件。
- 背景与透明部件为built-in image_gen原创制作；源PNG、提示词、图集测量记录位于source_assets/art/level02/。不是用整张概念图冒充关卡。三条新音乐与三音效由tools/generate_audio.py确定性合成，未使用外部游戏素材。
- 按关卡/检查点/纵向位置/Boss阶段/自动来源/run_id记录遥测，首个无效回调单列，自动记录不混入真人通关时长。
