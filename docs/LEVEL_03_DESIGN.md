# 第三关关卡规划：赤岩瀑布 · 断崖要塞

版本：已批准设计 v1.0 / 2026-11-04（Asia/Shanghai）  
状态：**用户已确认规划/UI并明确要求开发；执行计划见LEVEL_03_AGENT_DEVELOPMENT_PLAN.md，进度见LEVEL_03_PROGRESS.md。**  
当前基线：0.3.2阶段原型，两关/两个Boss，支持普通平台“正下＋跳”下穿。  
关联：[第二关纵向设计](LEVEL_02_VERTICAL_REDESIGN.md)、[下穿功能](evidence/drop-through/REPORT.md)、[现有验收规划](POLISH_MASTER_PLAN.md)。

## 1. 设计结论

第三关工作名称为**「赤岩瀑布 · 断崖要塞」**。从第二关坝顶穿过破损检修口，进入水坝外侧天然峡谷，沿瀑布两侧岩台向上突击，途中经过落石带、横移石台与短火焰栈道，最后在瀑布源头迎战嵌在岩壁中的大型要塞Boss。

核心体验：**观察上层威胁 → 在左右岩台间选路 → 跳跃/下穿调整位置 → 跨过移动石台 → 抵达顶部决战。**

本稿默认参考经典NES版《Contra / 魂斗罗》的第三关Waterfall，不混用街机版、Super C或其他续作的关号。参考关卡的空间与节奏，使用本项目原创地图、角色、造型和声音。

第三关继续以向上推进为主。和第二关的差别是：第二关为钢结构井道与规则平台组；第三关为开放峡谷、不规则岩台、短分路、落石与横移平台。不能只把第二关的钢板换成岩石贴图，也不能改成长距离横向跑图。

## 4. 空间与主路线

- 逻辑画布960×540，世界宽960，主要活动范围x=80～880；镜头x固定。
- 初版净攀升预算约2640，六段，约44～50次主线登高转换；最终平台数按实测可达性与节奏调整。
- 必经转换至少85%向上；通常2～4跳换一次方向。非战斗主线连续必要平跑≤160。
- 两处局部分路只延续同一个平台组，最多2～4跳后重新汇合；不做迷宫、不要求反复下楼开关。
- 下穿主要用于躲避、回收补给和回到另一条局部路线；主线不强制精确下穿才能完成。
- 每2～3次普通登高有可见承接台；不做屏幕底缘死亡或只进不退的卷屏。普通失足尽量只掉回几层。

```text
                瀑布源头 / 断崖要塞
         ┌───────────────────────────┐
         │ G：岩壁Boss，同屏仰射核心  │
         ├───────────────────────────┤
         │ F：峰顶突击 → Boss前平台  │
         │            ↑              │
         │ E：双侧岩台 + 横移台组合  │
         │       ↗    ↑    ↖         │
         │ D：短火焰栈道，向上换位   │
         │            ↑              │
         │ C：横移石台，先学登乘     │
         │       ↖    ↑    ↗         │
         │ B：落石示范 + 左右短分路  │
         │            ↑              │
         │ A：峡谷入口，宽岩台起步   │
         └───────────────────────────┘
```

示意为路线关系，不是最终坐标；横向箭头通过中间台连接，不能一次横跨整屏。G为F顶部接出的同屏战场，不计作额外长走廊。

## 5. 分段关卡编排

H表示相对出生点的登高高度。以下为编排预算，非已经实现或测得的时长。

| 段落 | 高度预算 | 玩家要做的判断 | 具体安排 | 压力/缓冲 |
| --- | --- | --- | --- | --- |
| A 峡口入侵 | H0～360 | 先看左上/右上岩台，建立自然地形落点感 | 前3跳无机关；之后一名可见步兵；宽承接台旁有不必拿的补给小台，可试下穿 | 低压力，约6次登高 |
| B 碎岩瀑道 | H360～840 | 等落石落过或从另一侧上行 | 第一处落石先单独展示；左路线短但需看落点，右路线多1～2跳但无落石；顶部汇合，一组侧炮塔 | 第一次分路，约8次登高；汇合处CP1 |
| C 浮岩渡口 | H840～1320 | 等石台靠近，登乘后在合适位置跳离 | 第一处水平横移岩台，无敌人同时压落脚点；下方固定兜底台可回到候台；后半才加入一名远侧步兵 | 移动平台教学，约8次登高 |
| D 灼流残桥 | H1320～1680 | 判断火焰周期，选择上层跳过或下层短绕行 | 一段短栈道和两处错开的岩缝火焰；可在宽台停留，不需要无敌道具；出口补给与CP2 | 短节奏变化，约6次登高 |
| E 夹击断崖 | H1680～2280 | 先处理哪一侧、是否下穿暂避再换路 | 第二处横移台与上下双路线；一处落石只覆盖一路，另一侧有可见炮塔；危险按组组合，不同时叠满全部机制 | 主挑战，约10次登高，有中间安全台 |
| F 峰顶突击 | H2280～2640 | 用已经学会的动作收束登高 | 左右岩台最后两轮换向，少量普通敌人，无新机关；远景逐渐露出要塞；CP3在Boss触发前 | 约6次登高；补给后直接进入Boss |
| G 岩壁要塞 | 顶部同屏 | 在移动避弹与向上输出之间切换 | 一整块实体底板、两处宽侧台、中央头顶弱点；击败后结算第三关 | 独立终点战 |

普通遭遇预算10～12组，不设每台清光封锁。不用无限出兵延长关卡。普通活动敌人上限6，通常2～3；落石/登乘教学阶段≤1，首次登乘不同时开火。

### 5.1 两个有代表性的游玩片段

**碎岩瀑道**：站在中央宽台，可以看到左上方碎石和落点边框；玩家可等一颗石头落过再跳左线，也可右上绕两跳。到汇合台后，两线的高度收益一致。不会为了拿必需钥匙再折返。

**夹击断崖**：上层炮塔控制右侧路径。玩家可先在左台斜上射击，也可利用下穿退到下层岩台，从横移台接近另一侧。下穿不是掉入盲区：按下前能看见下层承接面；不下穿也存在完整正常跳跃路线。

## 6. 新环境机制与边界

本关最多新增两种环境机制：**落石、水平横移平台**。火焰采用现有喷口预警/有效/冷却规则的主题化变体，不新增移动火球追踪系统。

### 6.1 落石

- 先给0.9～1.2秒可见前兆：岩缝碎屑、落点轮廓、低音提示；声音不能是唯一提示。
- 每次只落在一个固定小区域，不持续追踪玩家；预警开始即锁定位置。
- 初见为单颗，后段最多同时2颗；同一次组合保留完整安全落脚面。
- 玩家可避让或跳另一线；命中按普通1HP伤害与无敌规则处理，不一击必死、不额外击退进坑。
- 不把岩石实体堆积在台上，不做完整刚体/弹跳/碎片伤害。离开相关高度或Boss开始后清理，暂停冻结。
- 固定承接台和检查点落点不位于落石伤害区。返程也必须先预警，不能从屏外立即砸下。

### 6.2 横移岩台

- 首版仅水平往返，2个独立场景使用；不升降、不旋转、不坍塌、不挤压玩家。
- 台宽初始≥168，速度约40～60单位/秒，单侧行程约64～96；等待可登乘位置通常≤2秒，不能无意义拖时长。
- 明确显示运动方向与端点；首次登乘有固定候台、可见兜底台和回程连接，不用踩一个像素或极限卡时机。
- 站在台上时角色随台水平移动；起跳/下穿后立即脱离随台，不能被吸回或重复叠加速度。
- 对平台周期起点、中点、终点与换向都验证登乘/离台，不能只验证一个“最方便相位”。
- 不夹在两堵实体墙之间，也不把玩家带出x边界；关卡重试回到确定初态，安全恢复点只能在固定台。
- C段是一处受控主路渡台；E段移动台提供换位选择，固定台路线也能通关。移动台故障视为阻断，不临时用无敌/传送当修复。

### 6.3 岩缝火焰

先有琥珀轮廓/热气提示，再进入伤害状态。两处火焰错相，但不会把所有可达路线同时封死。普通跳跃和步枪可解，不靠新武器或无敌道具通过；低特效模式仍保留明确危险范围。

## 7. 地形、下穿与镜头

沿用现有速度245、起跳-540、重力1450，不为第三关改变前两关手感。普通高差40～60，最高64；普通平台宽≥144，转向/战斗台≥240，相邻落脚中心水平差通常≤110。移动台另按相对运动和完整周期验证，不能只看静态间距。

美术上区分两类表面：

- **完整厚岩壁/实体底板**：厚实连续岩层，不能下穿。
- **薄岩挑台/残桥/横移台**：底面悬空、边缘清楚，可从下方跳过，也可正下＋跳下穿。普通岩台外形不能画得像连续山体却实际可穿。

保持正下触发阈值、斜下不下穿、一次新按跳跃只穿当前层；不恢复原先容易误触的动作键布局。下穿后镜头跟随真实回落，高度进度记最高抵达固定层；不回滚检查点、不刷新收益。

镜头沿用着地推进、跳跃死区和可向下回看的方式，x固定；移动台水平运动不带动镜头摇摆。HUD、触控按钮后面不安排必须读的预警。上行前可看到下一落脚面，回落前可观察承接台。瀑布是背景层，不推人、不吸人、不挡弹、不遮挡敌弹。

## 8. 敌人、补给与公平性

继续使用步兵、炮塔、无人机三类，制作峡谷配色变化，不新增敌人种类。步兵布置于侧台，不突然从唯一落点出现；炮塔主要形成斜上/横向射线；无人机打破静止射击，但不整关追踪。

敌人进入实际可观察范围后完成预警才开火；不能藏在HUD或高不透明水幕中。新敌人在玩家落脚点旁出现时需安全距离/延迟，不能用接触伤害惩罚正常落地。

散弹补给预算3处：A/B交界、D出口、Boss前，均有固定台可取，不依赖移动台刷取。维持已有3HP/伤害规则，不新增回血、复活、武器种类或无限奖励来源。所有补给与击杀/目标分数按关卡和检查点记录一次；分路重返不重复刷。

## 9. 原创Boss：崖心堡垒

### 9.1 造型与战场

巨大装甲要塞嵌在瀑布源头岩壁内，中央为竖向水冷核心，左右是外露的短炮口和岩层装甲。轮廓为“厚重岩壁＋机械闸门”，不照搬原版异形头部或第二关双机械臂。

同屏底部为不可下穿的完整岩台，两处固定宽侧台提供斜上角度；主核心位于中上部，所有受击框都低于HUD。普通步枪的正上/斜上射击均有明确可达角度，不能要求新增向下瞄准或站到Boss身体内输出。

### 9.2 胜利规则

中央核心周期开放，开放前由装甲缝隙亮起提示。核心血量归零即结束。左右炮口为**可选减压目标**，破坏对应炮口减少一组侧向攻击，绝不是“先拆两个才解锁核心”。不打炮口也能完成，破坏后不复生、不重复计分。

核心窗口与攻击恢复相互交错，玩家应有稳定输出机会；窗口初步2～3秒，一个完整循环约4～5秒，可按正常步枪实测调整。关闭期可选择处理炮口，不靠长时间无事等待制造时长。Boss血量在Agent计划阶段按步枪命中/窗口预算确定，本稿不虚构已经平衡的数值。

### 9.3 攻击节奏

| 阶段 | 动作组合 | 玩家应对 | 公平性边界 |
| --- | --- | --- | --- |
| I 观察与拆解，HP100～60% | 单侧炮口少量定向弹，随后核心开放 | 平移避开，站稳仰射；也可先打侧炮口 | 炮口先亮再开火，不同时封两侧与中央 |
| II 换位输出，HP60～25% | 左右交替扇形弹；局部落石与核心开放交错 | 提前换侧，在输出与避让之间选择 | 一次主危险模式，落石不压住唯一输出位 |
| III 破壳收束，HP25～0% | 核心开放更频繁，交替沿用已学模式 | 利用更明显的窗口完成收尾 | 不临死加入未知秒杀技，不补回炮口血量 |

核心输出、炮口输出和落石预算统一计数；不能让三套独立计时器随机重叠成必伤。跳跃可避部分低位弹，侧台可下穿换位；战场底板始终受保护。普通敌人和外围机关在入场时清理/停用；胜利只结算一次。

演出：岩壁尘落→装甲开启→水冷核心亮起；死亡为炮口熄灭、核心裂解和水流恢复。控制闪光/震动，减少特效模式不删除战斗提示。

## 10. 检查点、回落与解锁

四个本次运行内检查点：CP0出生、CP1落石段汇合台H≈840、CP2火焰段出口H≈1680、CP3峰顶Boss前H≈2640。全部为固定宽安全台，不把横移台位置存为复活点。

沿用稳定序号/ID与快照：位置、最高进度、目标/炮口、已触发遭遇、消费拾取、分数按明确提交规则恢复。Boss前快照不保留上一次失败的Boss伤害；重试重置战场和攻击周期。回落只改变真实高度，不降低最高进度或退回旧检查点。

失足落入明确峡谷危险边界后，扣1HP并回到最近固定安全台；无敌时也要复位，最后1HP进入正常失败。不能以当前屏幕底边判死，移动台/机关台不能成为安全恢复点。

正式流程：第二关真实通关→解锁第三关；第三关锁定卡片提示条件，结算可选择进入第三关/返回选关；第三关通关后可重玩或选关。三关各自记录最高分。旧存档仅保留已知事实：有第二关最高分不代表曾通关，不据此自动解锁第三关；调试预览不写解锁和成绩。

第三张选关卡需重新安排三卡布局，不能挤压当前触屏命中区域。游戏内中途退出续关不纳入本次扩展。

## 11. 画面与声音方向

- 主色：暗赤褐/石灰岩，冷青瀑布与远处蓝灰山谷；危险为橙红，友方HUD仍为青色。保持已有细节位图和清楚装甲角色，不退回方块拼图。
- 地形：断裂岩台、苔痕、侵蚀水线、旧军用栈道、锚固钢梁；钢材仅作驻军设施，主要轮廓要能一眼认出天然峡谷。
- 背景三层：远山与天空、中景主瀑布/悬崖、近景支架与喷雾；低特效减少装饰，保留落石提示/台面边缘/敌弹。
- 不靠全屏水雾、持续抖动或整屏白闪营造“炫酷”；动态水幕不能洗掉角色轮廓。
- 音乐：原创峡谷突击、上层紧张变奏、Boss三段素材，复用现有混音/淡入淡出。流水环境声让位于枪声和危险提示，落石有提前碎裂声与命中声。
- 全部新图形/音乐/音效原创，保留分层/生成源、提示记录、锚点与许可清单；概念图只作审阅，不能作为整张不可交互的游戏背景替代资产。

## 12. 节奏与难度目标

熟悉操作后完整成功软目标约4～6分钟，Boss约45～75秒；不含死亡重试与暂停，均未验证，分段预算不作为达标证据。第三关比第二关多“观察移动/落石”的判断，难度主要来自选择和组合，而非加血、加速弹丸或让平台变窄。

至少3次正常真人完整成功后再判断是否调整。若偏短，增加有意义的落脚/交火变化；若偏长，删重复跳台和等待。不能用无敌回放时长代表真人目标，不能强制等待、无限敌人或提高HP凑分钟数。
